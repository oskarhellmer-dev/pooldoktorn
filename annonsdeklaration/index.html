Annonsdeklaration

Pooldoktorn.se finansieras genom annonser och affiliatelänkar. Det innebär att vissa länkar till butiker och leverantörer är sponsrade eller affiliatelänkar. Handlar du via en sådan länk kan vi få en provision.

Vad det betyder för dig

  • Priset blir detsamma för dig — provisionen betalas av butiken.
  • Vi rekommenderar inte produkter vi inte tror är relevanta bara för att få provision.
  • Länkar med kommersiellt syfte är märkta och satta med rel-attribut.

Frågor om annonsering? Kontakta oss via adressen i sidfoten.

Pooldoktorn — oberoende guider för pool och spa. Vi säljer inga produkter själva.
